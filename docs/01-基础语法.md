## 变量与常量

### val 与 var

在 Kotlin 中，有两种变量声明方式：

- **`val`**（value）：只读变量，声明后不可重新赋值（类似 Java 的 `final`）
- **`var`**（variable）：可变变量，可以重新赋值

```kotlin
val readOnly: Int = 10  // 只读变量
var mutable: Int = 20   // 可变变量

// readOnly = 30  // 错误！val 不能重新赋值
mutable = 30      // 正确
```

### 类型推断

Kotlin 具有强大的类型推断能力，可以自动推断变量类型：

```kotlin
val inferredInt = 42              // 自动推断为 Int
val inferredString = "Hello"      // 自动推断为 String
val inferredDouble = 3.14         // 自动推断为 Double
```

### 字符串模板

使用 `$` 符号可以在字符串中插入变量：

```kotlin
val name = "张三"
val age = 25
println("$name 今年 $age 岁")              // 简单变量
println("明年 ${age + 1} 岁")              // 表达式需要用 ${} 包裹
```

## 函数

### 基本函数定义

```kotlin
fun add(a: Int, b: Int): Int {
    return a + b
}
```

### 表达式体函数

对于简单函数，可以使用表达式体：

```kotlin
fun multiply(a: Int, b: Int): Int = a * b

// 返回类型可以省略（类型推断）
fun divide(a: Int, b: Int) = a / b
```

### 默认参数

```kotlin
fun greet(name: String = "访客", greeting: String = "你好") {
    println("$greeting, $name!")
}

greet()                              // 你好, 访客!
greet("李四")                         // 你好, 李四!
greet("王五", "晚上好")                // 晚上好, 王五!
```

### 命名参数

调用函数时可以指定参数名，提高可读性：

```kotlin
greet(name = "赵六")
greet(greeting = "早上好", name = "钱七")
```

### 可变参数

使用 `vararg` 关键字声明可变参数：

```kotlin
fun sumOf(vararg numbers: Int): Int {
    var total = 0
    for (num in numbers) {
        total += num
    }
    return total
}

val result = sumOf(1, 2, 3, 4, 5)  // 15
```

## 控制流

### if 表达式

在 Kotlin 中，`if` 是表达式，可以返回值：

```kotlin
val max = if (a > b) a else b

// 多行 if
val result = if (score >= 60) {
    println("及格")
    "PASS"
} else {
    println("不及格")
    "FAIL"
}
```

### when 表达式

`when` 类似其他语言的 `switch`，但更强大：

```kotlin
when (grade) {
    'A' -> println("优秀")
    'B' -> println("良好")
    'C' -> println("及格")
    'D', 'E' -> println("不及格")  // 多个条件
    else -> println("未知等级")
}

// when 作为表达式
val description = when (score) {
    in 90..100 -> "优秀"
    in 80..89 -> "良好"
    in 60..79 -> "及格"
    else -> "不及格"
}

// when 无参数形式
when {
    x.isOdd() -> println("x 是奇数")
    x.isEven() -> println("x 是偶数")
    else -> println("x 很奇怪")
}
```

### for 循环

```kotlin
// 遍历范围
for (i in 1..5) {
    println(i)  // 1, 2, 3, 4, 5
}

// 不包含结束值
for (i in 1 until 5) {
    println(i)  // 1, 2, 3, 4
}

// 倒序
for (i in 5 downTo 1) {
    println(i)  // 5, 4, 3, 2, 1
}

// 带步长
for (i in 0..10 step 2) {
    println(i)  // 0, 2, 4, 6, 8, 10
}

// 遍历集合
val fruits = listOf("苹果", "香蕉", "橙子")
for (fruit in fruits) {
    println(fruit)
}

// 带索引遍历
for ((index, fruit) in fruits.withIndex()) {
    println("$index: $fruit")
}
```

### while 循环

```kotlin
var count = 0
while (count < 5) {
    println(count)
    count++
}

// do-while
do {
    println("至少执行一次")
} while (false)
```

## 空安全

Kotlin 的空安全是其最重要的特性之一，可以在编译时防止 `NullPointerException`。

### 可空类型

```kotlin
var nonNullable: String = "Hello"
// nonNullable = null  // 编译错误！

var nullable: String? = "Hello"
nullable = null  // 正确
```

### 安全调用操作符 ?.

```kotlin
val length = nullable?.length  // 如果 nullable 为 null，返回 null
```

### Elvis 操作符 ?:

提供默认值：

```kotlin
val length = nullable?.length ?: 0  // 如果为 null，使用默认值 0
```

### 非空断言 !!

告诉编译器"我确定这不是 null"：

```kotlin
val definitelyNotNull = nullable!!.length  // 如果为 null，抛出异常
```

**警告**：尽量避免使用 `!!`，除非你非常确定不会为 null。

### let 函数

只在非 null 时执行代码块：

```kotlin
nullable?.let {
    println("字符串长度：${it.length}")
    println("转大写：${it.uppercase()}")
}
```

### 可空类型的集合

```kotlin
val nullableList: List<String>? = null  // 列表本身可以为 null
val listOfNullables: List<String?> = listOf("A", null, "B")  // 列表元素可以为 null
```
