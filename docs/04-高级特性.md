## 数据类

数据类（`data class`）主要用于存储数据，自动生成 `toString()`、`equals()`、`hashCode()`、`copy()` 等方法。

```kotlin
data class User(val name: String, val age: Int)

val user = User("Alice", 25)
println(user)         // User(name=Alice, age=25)

val olderUser = user.copy(age = 30)
println(olderUser)    // User(name=Alice, age=30)
```

### 解构声明

```kotlin
val (name, age) = user
println("name = $name, age = $age")
```

### Pair 与 Triple

```kotlin
val pair = Pair("苹果", 10.5)
val triple = Triple("香蕉", 20.0, true)
println(pair.first)
println(triple.second)
```

## 密封类

密封类（`sealed class`）限制类层次结构，所有子类都必须定义在同一个文件中。常用于表示有限的状态或结果。

```kotlin
sealed class ApiResult {
    data class Success(val data: String): ApiResult()
    data class Error(val code: Int, val message: String): ApiResult()
    object Loading: ApiResult()
}

fun handleResult(result: ApiResult): String = when (result) {
    is ApiResult.Success -> "成功: ${result.data}"
    is ApiResult.Error -> "失败: ${result.code} - ${result.message}"
    ApiResult.Loading -> "加载中"
}
```

**优点**：`when` 表达式对所有分支进行枚举，编译器会提醒漏掉的分支。

## 扩展函数与扩展属性

扩展函数可以为已有类添加新功能，而无需继承或修改原类。

```kotlin
fun String.withBrackets(): String = "[$this]"

println("Kotlin".withBrackets())  // [Kotlin]
```

扩展属性：

```kotlin
val String.firstLetter: Char
    get() = this.first()

println("Kotlin".firstLetter)  // K
```

### 注意事项

- 扩展函数不会真正修改类，只是通过静态函数实现
- 如果成员函数与扩展函数同名，成员函数优先

### 扩展函数的应用

```kotlin
fun MutableList<Int>.swap(i: Int, j: Int) {
    val temp = this[i]
    this[i] = this[j]
    this[j] = temp
}

val list = mutableListOf(1, 2, 3)
list.swap(0, 2)
println(list)  // [3, 2, 1]
```

## 高阶函数与内联函数

高阶函数指接收函数作为参数或返回函数的函数。

```kotlin
fun operate(data: List<Int>, block: (Int) -> Unit) {
    for (item in data) {
        block(item)
    }
}

operate(listOf(1, 2, 3)) { println(it) }
```

### 内联函数（inline）

内联函数可以减少高阶函数带来的性能开销。

```kotlin
inline fun <T> timeCost(block: () -> T): T {
    val start = System.nanoTime()
    val result = block()
    val end = System.nanoTime()
    println("耗时: ${end - start} ns")
    return result
}
```

### 函数引用

```kotlin
val names = listOf("Anna", "Bob")
val lengths = names.map(String::length)
```

## 协程概念

协程是 Kotlin 提供的轻量级线程，主要用于异步编程和并发任务。

### 协程的优势

- 轻量级：可以在一个线程中运行多个协程
- 非阻塞：挂起函数不会阻塞线程
- 结构化并发：使用 `CoroutineScope` 管理生命周期

### 基本示例（需要 kotlinx-coroutines 库）

```kotlin
suspend fun fetchData(): String {
    delay(1000)
    return "数据"
}

fun main() = runBlocking {
    val result = withContext(Dispatchers.IO) {
        fetchData()
    }
    println(result)
}
```
