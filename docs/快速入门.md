# Kotlin 学习项目 - 快速入门

欢迎！本文档将帮助您在 5 分钟内快速开始 Kotlin 学习之旅。

## 第一步：确认环境

### 检查 Java 版本

打开终端，执行：

```bash
java -version
```

应该看到版本号 ≥ 11。如果没有安装 Java，请访问：
- https://adoptium.net/（推荐）
- https://www.oracle.com/java/technologies/downloads/

## 第二步：运行项目

### 1. 进入项目目录

```bash
cd kotlin-learning
```

### 2. 运行示例代码

**Linux / macOS:**
```bash
./gradlew run
```

**Windows:**
```bash
gradlew.bat run
```

第一次运行会下载依赖，可能需要几分钟。

### 3. 查看输出

您应该看到类似输出：

```
============================================================
欢迎来到 Kotlin 学习项目！
============================================================

【第一部分：基础语法】
------------------------------------------------------------
1. 变量和常量
  只读变量 readOnly = 10
  可变变量 mutable = 20
  ...
```

## 第三步：开始学习

### 建议的学习路线

1. **第 1 天**：基础语法
   - 阅读：`docs/01-基础语法.md`
   - 代码：`src/main/kotlin/com/kotlinlearning/basics/BasicSyntaxExamples.kt`
   - 尝试修改代码中的变量和函数

2. **第 2 天**：类型检查与转换
   - 阅读：`docs/02-类型检查与转换.md`
   - 代码：`src/main/kotlin/com/kotlinlearning/typechecks/TypeCheckExamples.kt`
   - 创建自己的类层次并尝试类型检查

3. **第 3-4 天**：标准库函数
   - 阅读：`docs/03-标准库函数.md`
   - 代码：`src/main/kotlin/com/kotlinlearning/stdlib/StandardLibraryExamples.kt`
   - 练习集合操作和作用域函数

4. **第 5 天**：高级特性
   - 阅读：`docs/04-高级特性.md`
   - 代码：`src/main/kotlin/com/kotlinlearning/advanced/AdvancedExamples.kt`
   - 尝试编写扩展函数和高阶函数

## 第四步：动手练习

### 修改示例代码

1. 打开 `src/main/kotlin/com/kotlinlearning/basics/BasicSyntaxExamples.kt`
2. 找到 `variablesExample()` 函数
3. 添加自己的变量声明和打印：

```kotlin
val myName = "你的名字"
val myAge = 25
println("我是 $myName，今年 $myAge 岁")
```

4. 重新运行：`./gradlew run`

### 创建新的示例文件

在 `src/main/kotlin/com/kotlinlearning/basics/` 目录创建 `MyFirstExample.kt`：

```kotlin
package com.kotlinlearning.basics

fun myFirstExample() {
    println("这是我的第一个 Kotlin 示例！")
    
    val numbers = listOf(1, 2, 3, 4, 5)
    val doubled = numbers.map { it * 2 }
    println("原始列表：$numbers")
    println("翻倍后：$doubled")
}
```

然后在 `Main.kt` 中调用：

```kotlin
import com.kotlinlearning.basics.myFirstExample

fun main() {
    // ... 其他代码
    myFirstExample()
}
```

## 第五步：使用 IDE

### 使用 IntelliJ IDEA（推荐）

1. 下载并安装 [IntelliJ IDEA Community Edition](https://www.jetbrains.com/idea/download/)
2. 打开 IDEA，选择 `File` -> `Open`
3. 选择项目目录 `kotlin-learning`
4. 等待 Gradle 导入完成
5. 打开 `Main.kt`，点击 `main` 函数旁边的绿色运行按钮

### IDE 的优势

- 代码自动补全
- 即时错误检查
- 快速导航
- 调试功能

## 常见问题

### Q: 运行时提示 "command not found: java"

**A**: 您需要先安装 Java JDK。访问 https://adoptium.net/ 下载安装。

### Q: 下载依赖很慢

**A**: 可以配置国内镜像。编辑 `build.gradle.kts`，在 `repositories` 块中添加：

```kotlin
repositories {
    maven { url = uri("https://maven.aliyun.com/repository/public") }
    mavenCentral()
}
```

### Q: 我想只运行某个示例模块

**A**: 您可以在对应的文件中临时添加 `main` 函数：

```kotlin
fun main() {
    runBasicSyntaxExamples()
}
```

然后在 IDE 中右键运行该文件。
