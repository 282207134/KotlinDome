## is 和 !is

`is` 用于判断对象是否属于某个类型，`!is` 则表示不是某个类型。

```kotlin
val obj: Any = "Hello"

if (obj is String) {
    println(obj.length)  // 编译器自动将 obj 视为 String
}

if (obj !is Int) {
    println("obj 不是 Int 类型")
}
```

示例：

```kotlin
val shape: Shape = Circle(5.0)

if (shape is Circle) {
    println("圆的半径 = ${shape.radius}")
} else if (shape is Rectangle) {
    println("矩形面积 = ${shape.width * shape.height}")
}
```

## 智能类型转换（Smart Cast）

Kotlin 编译器会在确定类型的情况下自动进行类型转换，无需显式 `cast`。

```kotlin
fun printShape(shape: Shape) {
    if (shape is Circle) {
        // 这里 shape 自动被视为 Circle 类型
        println("半径 = ${shape.radius}")
    }
}
```

当编译器无法确定安全性（例如变量在多线程中可能被修改），则不会自动转换。

```kotlin
fun unsafeCast(shape: Shape) {
    if (shape is Rectangle) {
        shape = Circle(1.0)  // 编译错误：smart cast 不可用
    }
}
```

## 安全类型转换 as?

`as?` 是安全的类型转换，如果转换失败，返回 `null`，不会抛出异常。

```kotlin
val shape: Shape = Circle(2.5)
val circle: Circle? = shape as? Circle  // 成功转换
val rectangle: Rectangle? = shape as? Rectangle  // 转换失败，返回 null
```

常见用法：

```kotlin
val items: List<Any> = listOf(1, "Hello", Circle(3.0))
val circles = items.mapNotNull { it as? Circle }
```

---

## 强制转换 as

`as` 是不安全的类型转换，如果转换失败，会抛出 `ClassCastException`。

```kotlin
val shape: Shape = Circle(2.5)
val rectangle = shape as Rectangle  // 运行时错误！
```

**建议**：只有在你百分百确定类型时才使用 `as`，否则应选择 `as?`。

## when 与类型判断

`when` 可以用来判断类型并结合智能转换。

```kotlin
fun describe(input: Any): String = when (input) {
    is Int -> "整数"
    is String -> "字符串"
    is List<*> -> "列表"
    is Shape -> when (input) {
        is Circle -> "圆形"
        is Rectangle -> "矩形"
        else -> "未知形状"
    }
    else -> "无法识别"
}
```

`when` 也可以用于判断范围、枚举等。

```kotlin
when (score) {
    in 90..100 -> "优秀"
    in 60..89 -> "及格"
    else -> "不及格"
}
```

## 自定义类型检查逻辑

示例：判断 `Person` 是否成年。

```kotlin
data class Person(val name: String, val age: Int?)

fun checkAdult(person: Person) {
    if (person.age != null && person.age >= 18) {
        println("${person.name} 是成年人")
    } else {
        println("${person.name} 的年龄未知或未成年")
    }
}
```

利用智能类型转换，`person.age` 在 `if` 中被视为非空。
