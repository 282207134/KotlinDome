# Kotlin 学习项目使用文档

## 简介

本文档将指导您如何使用本 Kotlin 学习项目，从环境配置到运行示例，再到自定义练习。

---

## 环境要求

### 必需软件

- **Java JDK**: 版本 11 或更高
  - 下载地址：https://adoptium.net/ 或 https://www.oracle.com/java/technologies/downloads/
- **Gradle**（可选）：项目已包含 Gradle Wrapper，无需单独安装

### 推荐 IDE

- **IntelliJ IDEA**（推荐）：https://www.jetbrains.com/idea/
  - Community Edition（免费）即可
  - 自带 Kotlin 支持
- **Android Studio**：https://developer.android.com/studio
- **VS Code** + Kotlin 插件

---

## 环境配置

### 1. 检查 Java 安装

打开终端或命令提示符，运行：

```bash
java -version
```

应该看到类似输出：

```
openjdk version "17.0.2" 2022-01-18
```

如果提示 `command not found` 或版本低于 11，请先安装或更新 Java。

### 2. 克隆或下载项目

```bash
git clone <项目地址>
cd kotlin-learning
```

### 3. 使用 Gradle Wrapper（推荐）

项目自带 Gradle Wrapper，无需安装 Gradle：

- **Linux/macOS**：`./gradlew`
- **Windows**：`gradlew.bat`

---

## 项目运行

### 运行所有示例

```bash
./gradlew run
```

或在 Windows 上：

```bash
gradlew.bat run
```

这将运行 `Main.kt` 中的所有示例代码，输出会显示在终端。

### 编译项目

```bash
./gradlew build
```

编译后的 `.class` 文件会生成在 `build/` 目录。

### 清理项目

```bash
./gradlew clean
```

## 使用 IntelliJ IDEA

### 导入项目

1. 打开 IntelliJ IDEA
2. 选择 `File` -> `Open`
3. 选择项目目录 `kotlin-learning`
4. IDEA 会自动识别 Gradle 项目并导入

### 运行示例

1. 打开 `src/main/kotlin/com/kotlinlearning/Main.kt`
2. 点击 `main` 函数左侧的绿色运行按钮
3. 查看输出窗口

### 运行单个模块

如果只想运行某个模块（如基础语法），可以：

1. 打开对应文件（如 `BasicSyntaxExamples.kt`）
2. 在文件中添加临时 `main` 函数：
   ```kotlin
   fun main() {
       runBasicSyntaxExamples()
   }
   ```
3. 运行该文件

## 学习路径建议

### 第一阶段：基础语法（1-2 天）

1. 阅读 `docs/01-基础语法.md`
2. 运行 `BasicSyntaxExamples.kt` 中的代码
3. 修改代码，观察输出变化
4. 完成文档末尾的练习题

**重点掌握**：
- `val` 和 `var` 的区别
- 字符串模板
- `when` 表达式
- 空安全

### 第二阶段：类型检查（1 天）

1. 阅读 `docs/02-类型检查与转换.md`
2. 运行 `TypeCheckExamples.kt` 中的代码
3. 尝试创建自己的类层次并实践类型检查

**重点掌握**：
- `is` 和智能类型转换
- `as?` 安全转换
- `when` 与类型判断结合

### 第三阶段：标准库（2-3 天）

1. 阅读 `docs/03-标准库函数.md`
2. 运行 `StandardLibraryExamples.kt` 中的代码
3. 尝试使用各种集合操作函数

**重点掌握**：
- 集合操作（`map`、`filter`、`reduce` 等）
- 作用域函数（`let`、`run`、`apply` 等）
- 序列的惰性求值

### 第四阶段：高级特性（2-3 天）

1. 阅读 `docs/04-高级特性.md`
2. 运行 `AdvancedExamples.kt` 中的代码
3. 尝试实现自己的扩展函数和高阶函数

**重点掌握**：
- 数据类和解构
- 密封类
- 扩展函数
- 高阶函数和内联函数

## 自定义练习

### 添加新的示例代码

1. 在对应模块目录下创建新文件
2. 例如，在 `basics/` 目录创建 `MyExample.kt`：
   ```kotlin
   package com.kotlinlearning.basics
   
   fun myCustomExample() {
       println("这是我的自定义示例")
   }
   ```
3. 在 `Main.kt` 中调用该函数

### 编写测试

1. 在 `src/test/kotlin/` 目录下创建测试文件
2. 使用 Kotlin Test 编写单元测试
3. 运行测试：`./gradlew test`

## 常见问题

### Q: 运行时提示找不到 Java

**A**: 请确保已安装 JDK 并配置了 `JAVA_HOME` 环境变量。

### Q: Gradle 下载依赖很慢

**A**: 可以配置国内镜像，编辑 `build.gradle.kts`：

```kotlin
repositories {
    maven { url = uri("https://maven.aliyun.com/repository/public") }
    mavenCentral()
}
```

### Q: IntelliJ IDEA 无法识别 Kotlin 代码

**A**: 确保已安装 Kotlin 插件（`Preferences` -> `Plugins`）。

### Q: 如何添加协程库

**A**: 在 `build.gradle.kts` 的 `dependencies` 块中添加：

```kotlin
dependencies {
    implementation("org.jetbrains.kotlinx:kotlinx-coroutines-core:1.7.3")
}
```
